# HyDE Arch Dotfiles

## Setup

- Install Arch using `archinstall`
  - Selections: minimal profile; systemd-boot; LUKS2; UKI disabled, Btrfs; linux (primary) and linux-lts (fallback); ZRAM+LZ4; Snapper; PipeWire; NetworkManager; multilib; powerprofilesctl; all additional fonts; holychowders with sudo
    - Additional packages: git, base-devel, intel-ucode, linux-headers, linux-lts-headers
- Install HyDE
  - Selections:
- Run `install.sh`
